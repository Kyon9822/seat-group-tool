  2. 右上の + → New repository をクリック
  3. リポジトリ名を入力（例：seat-group-tool）
  4. Public を選択
  5. Create repository をクリック

ステップ2: ファイルをアップロード

  1. リポジトリページで Add file → Upload files をクリック
  2. HTMLファイルをドラッグ&ドロップするか選択
  3. 名前を index.html に変更（重要）
  4. Commit changes をクリック

ステップ3: GitHub Pagesを有効化

  1. リポジトリの Settings をクリック
  2. 左側メニューから Pages をクリック
  3. Source の下で：
    • Branch: main を選択
    • Folder: / (root) を選択
  4. Save をクリック

完了！
